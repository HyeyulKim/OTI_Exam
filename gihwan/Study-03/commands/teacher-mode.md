# 교사 모드 통합 실행

여러 학생의 퀴즈 성적을 조회하고 비교·분석하여 하나의 교사용 보고서로 제공한다.

## 실행 순서

다음 명령의 기능을 순서대로 수행한다.

1. `teacher-roster`: 저장된 학생 성적과 손상 기록 확인
2. `teacher-compare`: 학생별 백분율, 순위, 평균 대비 차이 비교
3. `teacher-analysis`: 성취 구간과 학습 분석
4. `teacher-report`: 앞선 결과를 하나의 보고서로 통합

## `$ARGUMENTS` 처리

- 인자가 없으면 전체 학생을 대상으로 실행한다.
- 인자가 있으면 다음 중 하나로 해석한다.
  - 닉네임: 해당 학생 중심으로 조회하되 전체 비교 기준도 함께 표시
  - 쉼표로 구분한 닉네임: 지정한 학생들만 비교
  - 카테고리명: 해당 카테고리 기록만 분석
  - `요약`: 전체 학생의 요약 보고서 생성
  - `상세`: 학생별 결과와 제한 사항까지 포함한 상세 보고서 생성

## 공통 데이터 규칙

- `Study-03/script.js`의 `normalization-quiz-ranking` 저장 키와 정렬 규칙을 따른다.
- 점수 비율을 우선 비교 기준으로 사용한다.
- 총 문항 수가 다른 기록은 원점수가 아니라 백분율로 비교한다.
- 문항별 풀이 기록과 카테고리별 점수가 저장되어 있지 않으면 이를 명확하게 보고한다.
- 확인할 수 없는 값은 추측하지 않는다.
- 원본 데이터는 읽기만 하며 변경하지 않는다.

## 최종 출력 형식

```text
# 교사 모드 성적 대시보드

## 한눈에 보기
- 분석 학생 수:
- 응시 기록 수:
- 평균:
- 최고점:
- 최저점:

## 학생별 비교
| 순위 | 학생 | 점수 | 백분율 | 성취 구간 |
|---:|---|---:|---:|---|

## 학습 분석
- 성취 구간별 분포
- 카테고리별 분석
- 문항별 분석

## 수업 제안
- 복습 우선순위
- 추가로 수집할 데이터

## 데이터 제한
- 손상·누락 기록
- 현재 게임에서 저장하지 않는 통계
```

## 실행 지침

1. 저장 데이터와 현재 게임의 랭킹 로직을 확인한다.
2. 학생 성적 목록을 만든다.
3. 학생 간 비교 통계를 계산한다.
4. 가능한 범위의 학습 분석을 수행한다.
5. 모든 결과를 보고서 형식으로 통합한다.
6. 각 수치의 표본 수와 데이터 범위를 함께 표시한다.
7. 성적 기록과 원본 문항을 수정하지 않는다.
