# 퀴즈 통계 관리

퀴즈 문항 데이터와 게임에 저장된 플레이 기록을 읽어 퀴즈 통계를 집계하고 관리한다.

## 통계 범위

`Study-03/data/questions.js`에서 다음 문항 통계를 계산한다.

- 전체 문항 수
- 카테고리별 문항 수
- 카테고리별 정답 선택지 분포
- 전체 정답 선택지 분포
- 보기 수가 4개가 아닌 문항
- 유효하지 않은 `answer` 인덱스
- 질문·보기·해설이 비어 있는 문항

`Study-03/script.js`와 브라우저 저장 데이터에서 확인할 수 있는 플레이 통계도 구분하여 보고한다.

- 랭킹 기록 수
- 랭킹 기록의 평균 점수 비율
- 최고 점수 비율과 해당 닉네임
- 카테고리별 통계가 저장되어 있는지 여부
- 문항별 정답률 데이터가 저장되어 있는지 여부

현재 코드에 문항별 풀이 기록 저장 기능이 없으면 이를 `수집되지 않음`으로 명확히 표시하고 추측하지 않는다.

## `$ARGUMENTS` 처리

- 인자가 없으면 전체 카테고리 통계를 집계한다.
- `$ARGUMENTS`가 있으면 해당 카테고리만 집계한다.
- `1nf`/`제1정규화`, `2nf`/`제2정규화`, `3nf`/`제3정규화`, `denormalization`/`반정규화`를 허용한다.
- 유효하지 않은 카테고리면 사용 가능한 카테고리를 안내하고 집계를 중단한다.

## 출력 형식

```text
## 문항 통계
- 검사 범위: 전체 또는 카테고리
- 문항 수: 숫자
- 카테고리별 문항 수: 목록
- 정답 분포: ① 0개, ② 0개, ③ 0개, ④ 0개

## 데이터 품질
- 보기 수 오류: 없음 또는 목록
- 정답 인덱스 오류: 없음 또는 목록
- 빈 필드: 없음 또는 목록

## 플레이 통계
- 랭킹 기록 수: 숫자 또는 확인 불가
- 평균 점수 비율: 백분율 또는 확인 불가
- 최고 기록: 닉네임, 점수 또는 없음
- 문항별 정답률: 수집됨 또는 수집되지 않음

## 관리 의견
- 통계에서 확인된 이상 또는 개선 권장 사항
```

## 실행 지침

1. `questions.js`와 `script.js`를 읽는다.
2. 필요한 경우 브라우저의 `normalization-quiz-ranking` 저장 데이터를 확인한다.
3. 문항 데이터 통계와 플레이 기록 통계를 섞지 않고 별도로 집계한다.
4. 백분율은 표본 수를 함께 표시하고, 표본이 없으면 계산하지 않는다.
5. 확인할 수 없는 통계는 추측하지 않고 `수집되지 않음` 또는 `확인 불가`로 표시한다.
6. 통계나 게임 코드를 임의로 수정하지 않고 결과와 관리 의견만 출력한다.
