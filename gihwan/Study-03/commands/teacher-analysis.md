# 교사 모드 학습 분석

퀴즈 문항 데이터와 학생 성적 기록을 분석해 수업 개선에 필요한 정보를 제공한다.

## 분석 항목

### 학급 수준

- 전체 학생 수와 응시 기록 수
- 평균, 중앙값, 최고점, 최저점
- 점수 구간별 학생 수: 90% 이상, 70~89%, 50~69%, 50% 미만
- 총점이 다른 기록의 백분율 정규화 여부

### 문항 수준

- 문항별 정답 데이터가 저장되어 있는지 확인한다.
- 문항별 정답률이 없으면 `문항별 정답률 수집 불가`로 보고한다.
- 저장된 경우 정답률이 낮은 문항과 카테고리를 식별한다.

### 카테고리 수준

- 응시 기록에 카테고리별 점수가 저장되어 있는지 확인한다.
- 저장된 경우 카테고리별 평균과 학생별 편차를 계산한다.
- 저장되지 않은 경우 현재 데이터만으로 카테고리 취약점을 판단하지 않는다.

## 성취 구간 해석

- 90% 이상: 높은 성취
- 70~89%: 기본 개념은 확보했으나 추가 확인 필요
- 50~69%: 핵심 개념 보강 필요
- 50% 미만: 기초 개념부터 재학습 권장

이 구간은 참고용이며 학생을 단정하거나 낙인찍는 표현을 사용하지 않는다.

## 출력 형식

```text
## 학습 분석
- 분석 학생 수: 숫자
- 유효 응시 기록: 숫자
- 평균: 백분율
- 중앙값: 백분율

## 성취 구간
- 높은 성취: 학생 수와 목록
- 기본 개념 확보: 학생 수와 목록
- 핵심 개념 보강 필요: 학생 수와 목록
- 기초부터 재학습 권장: 학생 수와 목록

## 취약 영역
- 카테고리별: 수집됨 또는 수집 불가
- 문항별: 수집됨 또는 수집 불가

## 수업 제안
- 데이터로 뒷받침되는 복습 제안
- 추가로 수집해야 할 데이터
```

## 실행 지침

1. `Study-03/data/questions.js`, `Study-03/script.js`, 랭킹 저장 데이터를 확인한다.
2. 확인 가능한 통계만 계산한다.
3. 문항별 풀이 기록이 없으면 정답률을 만들어내지 않는다.
4. 학생 이름과 성적은 필요한 범위에서만 표시한다.
5. 분석 결과는 학생 지원과 수업 개선 목적의 중립적인 표현으로 작성한다.
