# 교사 모드 성적 보고서

학생 성적 조회, 비교, 학습 분석 결과를 교사가 공유할 수 있는 하나의 보고서로 정리한다.

## 보고서 구성

1. 보고서 제목과 생성 시각
2. 분석 대상과 응시 기록 수
3. 학생별 순위표
4. 평균·중앙값·최고점·최저점
5. 학생 간 비교 요약
6. 성취 구간별 분포
7. 카테고리별·문항별 분석 가능 여부
8. 수업 복습 제안
9. 데이터 제한과 확인 필요 사항

## 작성 규칙

- 점수와 백분율을 함께 표시한다.
- 총 문항 수가 다르면 백분율로 비교한다.
- 동일 점수는 공동 순위로 처리한다.
- 점수 백분율 내림차순의 상대 순위로 등급을 부여한다.
- 상위 20%는 A, 상위 40%는 B, 상위 70%는 C, 하위 30%는 D로 표시한다.
- 등급 경계 동점자는 동일 등급으로 처리하고 실제 등급별 인원을 함께 표시한다.
- 문항별 풀이 기록이 없으면 카테고리 취약점을 추정하지 않는다.
- 손상되거나 누락된 기록은 보고서 본문과 분리해 표시한다.
- 학생을 비난하거나 공개적으로 낙인찍는 표현을 사용하지 않는다.
- 개인정보는 필요한 범위의 닉네임만 사용한다.

## 출력 형식

```text
# 정규화 퀴즈 교사 성적 보고서

- 생성 시각: 날짜와 시간
- 대상: 학생 수, 응시 기록 수

## 학생별 결과
| 순위 | 학생 | 점수 | 백분율 | 등급 |
|---:|---|---:|---:|:---:|

## 전체 통계
- 평균:
- 중앙값:
- 최고점:
- 최저점:

## 상대평가 등급 분포
- A(상위 20%):
- B(상위 40%):
- C(상위 70%):
- D(하위 30%):

## 비교 및 학습 분석
- 주요 결과
- 성취 구간 분포
- 복습이 필요한 영역

## 데이터 제한
- 현재 저장되지 않아 확인할 수 없는 항목
```

## 실행 지침

1. `teacher-roster`, `teacher-compare`, `teacher-analysis` 결과를 통합한다.
2. 동일한 기록을 중복 집계하지 않는다.
3. 수치와 해석을 구분한다.
4. 보고서만 출력하고 원본 성적이나 랭킹 데이터를 수정하지 않는다.
