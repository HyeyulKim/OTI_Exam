# 교사 모드 학생 성적 조회

퀴즈 게임에 저장된 여러 학생의 성적 기록을 읽어 교사가 한눈에 확인할 수 있는 성적 목록을 만든다.

## 데이터 출처

- 브라우저 `localStorage`의 `normalization-quiz-ranking` 데이터를 사용한다.
- 각 기록의 `nickname`, `score`, `total`, `createdAt`을 확인한다.
- 저장 데이터가 없거나 읽을 수 없으면 그 사실을 명시한다.

## 처리 규칙

- 점수 비율을 `score / total * 100`으로 계산한다.
- 점수 비율 내림차순으로 정렬한다.
- 점수 비율이 같으면 원점수 내림차순, 그래도 같으면 기록 시각이 빠른 순서로 정렬한다.
- 닉네임, 점수, 총점, 백분율, 기록 시각, 순위를 표시한다.
- 손상된 기록은 정상 성적과 분리해 표시하고 임의로 수정하거나 삭제하지 않는다.

## `$ARGUMENTS` 처리

- 인자가 없으면 전체 학생을 조회한다.
- 인자가 있으면 해당 닉네임이 포함된 학생만 조회한다.

## 출력 형식

```text
## 학생 성적 목록
| 순위 | 학생 | 점수 | 백분율 | 기록 시각 |
|---:|---|---:|---:|---|
| 1 | 학생명 | 38/40 | 95% | 날짜와 시간 |

## 확인 필요 기록
- 없음 또는 손상 기록 목록
```

## 실행 지침

1. `Study-03/script.js`의 랭킹 저장 키와 정렬 규칙을 확인한다.
2. 저장된 모든 기록을 읽고 유효성을 검증한다.
3. 유효한 기록만 순위표에 포함한다.
4. 현재 데이터에 학생별 응시 이력이나 카테고리별 점수가 없으면 `수집되지 않음`으로 표시한다.
5. 조회만 수행하고 저장 데이터를 변경하지 않는다.
