# 교사 모드 학생 성적 비교

여러 학생의 퀴즈 성적을 동일한 기준으로 비교해 상대적인 성취 수준을 정리한다.

## 비교 지표

- 점수와 총점
- 점수 백분율
- 최고 점수, 최저 점수, 평균 점수
- 중앙값
- 최고점과 최저점의 차이
- 평균 대비 각 학생의 차이
- 동일 학생의 여러 기록이 있으면 응시 기록별로 구분

## 비교 규칙

- 백분율을 기본 비교 기준으로 사용한다.
- 총 문항 수가 다른 기록은 백분율을 우선하고 원점수를 직접 비교하지 않는다.
- 학생별 카테고리 점수 또는 문항별 정답률이 저장되어 있지 않으면 카테고리 비교를 추측하지 않는다.
- 동점은 공동 순위로 표시한다.
- 표본 수가 적으면 일반화하지 않고 표본 수를 함께 표시한다.

## `$ARGUMENTS` 처리

- 인자가 없으면 전체 학생 기록을 비교한다.
- 인자가 있으면 쉼표로 구분한 닉네임만 비교한다.
- 카테고리명이 인자로 주어지면 해당 카테고리 기록만 비교한다.

## 출력 형식

```text
## 학생 비교
| 학생 | 점수 | 백분율 | 순위 | 평균 대비 |
|---|---:|---:|---:|---:|
| 학생명 | 38/40 | 95% | 공동 1위 | +7.5%p |

## 비교 요약
- 평균: 87.5%
- 중앙값: 90%
- 최고점: 학생명 95%
- 최저점: 학생명 70%
- 점수 범위: 25%p

## 해석
- 상대적으로 높은 성취를 보인 학생
- 추가 관찰이 필요한 학생
- 해석할 수 없는 항목
```

## 실행 지침

1. `teacher-roster`와 동일한 저장 데이터를 사용한다.
2. 학생별 점수 백분율을 계산한다.
3. 평균과 중앙값은 유효한 기록만으로 계산한다.
4. 학생 간 차이를 사실과 해석으로 구분해 보고한다.
5. 성적 자체를 수정하거나 순위를 임의로 조정하지 않는다.
