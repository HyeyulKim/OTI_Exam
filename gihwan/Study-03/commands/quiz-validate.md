# 퀴즈 최상급 표현 검증

`$ARGUMENTS`를 카테고리로 사용하여 `Study-03/data/questions.js`의 퀴즈 문제를 검사한다.

## 검사 범위

- `$ARGUMENTS`가 비어 있으면 전체 카테고리를 검사한다.
- `$ARGUMENTS`가 입력되면 해당 카테고리의 문제만 검사한다.
- 다음 카테고리 식별자와 표시명을 모두 허용한다.
  - `1nf` 또는 `제1정규화`
  - `2nf` 또는 `제2정규화`
  - `3nf` 또는 `제3정규화`
  - `denormalization` 또는 `반정규화`
- 입력한 카테고리를 찾을 수 없으면 검사를 진행하지 말고 사용 가능한 카테고리 목록을 안내한다.

## 검사 대상

다음처럼 비교 기준이 불명확할 수 있는 최상급 표현이 포함된 문항을 찾는다.

- `가장`
- `최초`
- `최대`
- 위 표현의 활용형도 포함한다. 예: `최대한`, `최대화`

질문 문장뿐 아니라 보기와 해설도 함께 검사한다. 표현이 문항의 질문, 보기, 해설 중 어디에 포함되어 있는지도 구분한다.

각 표현을 발견하면 단순히 표현을 나열하지 말고, 문항의 의미에 맞춰 어떤 기준을 명시해야 하는지 함께 제안한다.

- `가장`: 비교 대상 범위, 평가 기준, 우선순위를 명시한다.
- `최초`: 시간 기준, 사건 또는 대상의 범위, 최초로 인정하는 조건을 명시한다.
- `최대`: 측정 기준, 단위, 비교 범위, 시점 또는 허용 한도를 명시한다.
- 활용형도 원래 표현의 기준에 따라 설명한다.

## 출력 형식

발견된 문항을 카테고리와 원본 문항 순서로 정렬하여 다음 형식의 목록으로 보여준다.

```text
- [카테고리] Q번호
  - 위치: 질문 | 보기 ①~④ | 해설
  - 표현: 발견된 표현
  - 문장: 해당 표현이 포함된 원문
  - 명시할 기준: 기준을 구체화한 제안
```

동일 문항에서 여러 표현이나 여러 위치가 발견되면 각각 빠짐없이 표시한다. 발견된 문항이 없으면 검사 범위를 포함해 `해당 범위에서 최상급 표현이 발견되지 않았습니다.`라고 출력한다. 마지막에 표현별 발견 개수와 전체 발견 개수를 요약한다.

## 실행 지침

1. `Study-03/data/questions.js`를 읽는다.
2. `$ARGUMENTS`가 있으면 해당 카테고리의 문항만 선택하고, 없으면 전체 문항을 선택한다.
3. 각 선택 문항의 `category`, 질문, `options`, `explanation`을 검사한다.
4. `categoryLabels`를 사용해 카테고리명을 표시한다.
5. 검색 결과의 문장은 수정하지 않고 원문 그대로 출력한다.
6. 각 발견 항목에 모호성을 해소하기 위해 필요한 기준을 구체적으로 제안한다.
7. 검사하지 않은 카테고리나 문항을 임의로 포함하거나 추정하지 않는다.
