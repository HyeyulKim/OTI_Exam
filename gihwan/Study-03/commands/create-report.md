# 교사 성적 보고서 생성

학생들의 퀴즈 성적을 비교해 `Study-03/commands/teacher_report.html` 파일로 생성한다.

## 상대평가 등급

학생을 점수 백분율 내림차순으로 정렬한 뒤 전체 유효 학생 수를 기준으로 상대평가 등급을 부여한다.

- 상위 20%: `A`
- 상위 40%: `B`
- 상위 70%: `C`
- 하위 30%: `D`

등급 경계는 학생 순위의 백분위로 계산한다. 동점자는 같은 점수 비율을 유지하며, 경계에서 임의로 학생을 분리하지 말고 동점 처리 방식과 실제 인원을 보고서에 표시한다.

## 보고서 내용

`Study-03/commands/teacher_report.html`에 다음을 포함한다.

- 보고서 생성 시각
- 전체 학생 수와 유효 기록 수
- 순위, 학생 닉네임, 점수, 백분율, 상대평가 등급
- 평균, 중앙값, 최고점, 최저점
- 등급별 학생 수와 비율
- 카테고리별·문항별 통계가 없으면 `수집되지 않음` 표시
- 손상되거나 누락된 기록

## 데이터 규칙

- `Study-03/script.js`의 `normalization-quiz-ranking` 저장 데이터를 사용한다.
- 점수 비율을 기본 순위 기준으로 사용한다.
- 총 문항 수가 다른 기록은 원점수가 아니라 백분율로 비교한다.
- 닉네임 외 불필요한 개인정보를 포함하지 않는다.
- 원본 성적과 랭킹 데이터는 수정하지 않는다.

## 실행 지침

1. `teacher-roster`, `teacher-compare`, `teacher-analysis`의 기능을 참고한다.
2. 유효한 학생 기록만 점수 비율 내림차순으로 정렬한다.
3. 상대평가 등급 기준에 따라 각 학생에게 A~D를 부여한다.
4. 등급 경계의 동점 처리와 실제 등급별 인원을 기록한다.
5. 결과를 읽기 쉬운 표와 요약 영역을 포함한 `Study-03/commands/teacher_report.html`로 저장한다.
6. 생성된 파일 경로와 등급별 인원을 출력한다.
